Enhancements relative to 1:
* Render multiple lines at once (still no scrolling, though)
* Some ubiquitous keyboard shortcuts: `enter`, `backspace`, `delete`, `tab`
* Smarter rects. You can click to the left or right of a line and the cursor
  will move to its start or end respectively.
* Encapsulation so it can be added to other projects.

Limitations:
* Still no keys for moving the cursor. Arrow keys, etc.
